1. Hinweise

Diese Datei zeigt die wichtigsten und praktisch relevanten Textformatierungen von Org Mode.

Die Syntaxbeispiele stehen überwiegend in Example-Blöcken, damit sie beim HTML- oder PDF-Export nicht selbst interpretiert werden.

2. Grundlegende Hervorhebungen

2.1. Fett

Syntax: 

*Dieser Text ist fett.*

Darstellung:

Dieser Text ist fett.

2.2. Kursiv

Syntax: 

/Dieser Text ist kursiv./

Darstellung:

Dieser Text ist kursiv.

2.3. Unterstrichen

Syntax: 

_Dieser Text ist unterstrichen._

Darstellung:

Dieser Text ist unterstrichen.

2.4. Durchgestrichen

Syntax: 

+Dieser Text ist durchgestrichen.+

Darstellung:

Dieser Text ist durchgestrichen.

2.5. Quellcode im Fließtext

Syntax: 

~doom sync~

Darstellung:

doom sync

2.6. Wörtlicher Text

Syntax: 

=Dieser Text wird wörtlich dargestellt.=

Darstellung:

Dieser Text wird wörtlich dargestellt.

3. Kombinationen von Hervorhebungen

*/fett und kursiv/*
*_fett und unterstrichen_*
/_unterstrichen und kursiv_/
*~fetter Code~*
/~kursiver Code~/

Hinweis: Nicht jede beliebige Verschachtelung wird von jedem Export-Backend gleich dargestellt. Einfachere Kombinationen sind robuster.

4. Regeln für Hervorhebungszeichen

Funktioniert normalerweise: 

Das ist *fett* und das ist /kursiv/.

Problematisch kann sein: 

Wort*mittenimwort*

Ein Leerzeichen direkt innerhalb der Begrenzungszeichen verhindert meist die Hervorhebung:

#+endexample

16. Zitate und besondere Textblöcke

16.1. Zitatblock

Dies ist ein Zitat.

#+end_quote

16.2. Example-Block

Die Syntax eines Example-Blocks wird hier als festbreiter Text mit Doppelpunkt-Präfix gezeigt, damit keine gleichartigen Blöcke ineinander verschachtelt werden: 

#+begin_example
Dieser Inhalt wird wörtlich dargestellt.
*Fettzeichen* werden nicht interpretiert.
#+end_example

16.3. Verse-Block

#+begin_verse
Erste Verszeile
  eingerückte Verszeile
Dritte Verszeile
#+end_verse

16.4. Center-Block

#+begin_center
Dieser Text wird beim Export zentriert.
#+end_center

16.5. Comment-Block

#+begin_comment
Dieser Text erscheint nicht im Export.
#+end_comment

16.6. Export-Block

#+begin_export html
<strong>Direktes HTML</strong>
#+end_export

17. Quellcodeblöcke

Allgemeine Syntax: 

#+begin_src SPRACHE
Quellcode
#+end_src

17.1. Shell

#+begin_src shell
printf '%s\n' "Hallo"
#+end_src

17.2. Python

#+begin_src python
print("Hallo aus Python")
#+end_src

17.3. Rust

#+begin_src rust
fn main() {
    println!("Hallo aus Rust");
}
#+end_src

17.4. Mojo

#+begin_src mojo
fn main():
    print("Hallo aus Mojo")
#+end_src

17.5. Header-Argumente

#+begin_src python :results output :exports both
print(2 + 3)
#+end_src
Argument Bedeutung
:results output Programmausgabe als Ergebnis
:results value Rückgabewert als Ergebnis
:exports code nur Code exportieren
:exports results nur Ergebnis exportieren
:exports both Code und Ergebnis exportieren
:exports none weder Code noch Ergebnis exportieren
:eval never Block nicht ausführen
:dir PFAD Arbeitsverzeichnis setzen

18. Inline-Quellcode

src_python{2 + 3}

Mit Ergebnisangabe: 

src_python[:results value]{2 + 3}

33. Exportoptionen

#+options: toc:3 num:t author:t date:t title:t
Option Bedeutung
toc:nil kein Inhaltsverzeichnis
toc:2 Inhaltsverzeichnis bis Ebene 2
num:nil Überschriften nicht nummerieren
num:t Überschriften nummerieren
author:nil Autor nicht exportieren
date:nil Datum nicht exportieren
title:nil Titel nicht exportieren
^:nil Hoch- und Tiefstellung deaktivieren
^:{} Hoch- und Tiefstellung nur mit Klammern
\n:t Zeilenumbrüche stärker erhalten
