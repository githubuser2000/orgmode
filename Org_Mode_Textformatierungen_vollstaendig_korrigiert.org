* Hinweise

Diese Datei zeigt die wichtigsten und praktisch relevanten
Textformatierungen von Org Mode.

Die Syntaxbeispiele stehen überwiegend in =Example=-Blöcken, damit sie
beim HTML- oder PDF-Export nicht selbst interpretiert werden.

* Grundlegende Hervorhebungen

** Fett

Syntax:

#+begin_example
*Dieser Text ist fett.*
#+end_example

Darstellung:

*Dieser Text ist fett.*

** Kursiv

Syntax:

#+begin_example
/Dieser Text ist kursiv./
#+end_example

Darstellung:

/Dieser Text ist kursiv./

** Unterstrichen

Syntax:

#+begin_example
_Dieser Text ist unterstrichen._
#+end_example

Darstellung:

_Dieser Text ist unterstrichen._

** Durchgestrichen

Syntax:

#+begin_example
+Dieser Text ist durchgestrichen.+
#+end_example

Darstellung:

+Dieser Text ist durchgestrichen.+

** Quellcode im Fließtext

Syntax:

#+begin_example
~doom sync~
#+end_example

Darstellung:

~doom sync~

** Wörtlicher Text

Syntax:

#+begin_example
=Dieser Text wird wörtlich dargestellt.=
#+end_example

Darstellung:

=Dieser Text wird wörtlich dargestellt.=

* Kombinationen von Hervorhebungen

#+begin_example
*/fett und kursiv/*
*_fett und unterstrichen_*
/_unterstrichen und kursiv_/
*~fetter Code~*
/~kursiver Code~/
#+end_example

Hinweis: Nicht jede beliebige Verschachtelung wird von jedem Export-Backend
gleich dargestellt. Einfachere Kombinationen sind robuster.

* Regeln für Hervorhebungszeichen

Funktioniert normalerweise:

#+begin_example
Das ist *fett* und das ist /kursiv/.
#+end_example

Problematisch kann sein:

#+begin_example
Wort*mittenimwort*
#+end_example

Ein Leerzeichen direkt innerhalb der Begrenzungszeichen verhindert meist
die Hervorhebung:

#+begin_example
* nicht fett *
#+end_example

** Example-Block

Die Syntax eines Example-Blocks wird hier als festbreiter Text mit
Doppelpunkt-Präfix gezeigt, damit keine gleichartigen Blöcke
ineinander verschachtelt werden:

: Dieser Inhalt wird wörtlich dargestellt.
: *Fettzeichen* werden nicht interpretiert.
: #+end_example

** Header-Argumente

#+begin_example
#+begin_src python :results output :exports both
print(2 + 3)
#+end_src
#+end_example

| Argument         | Bedeutung                            |
|------------------+--------------------------------------|
| :results output  | Programmausgabe als Ergebnis         |
| :results value   | Rückgabewert als Ergebnis            |
| :exports code    | nur Code exportieren                 |
| :exports results | nur Ergebnis exportieren             |
| :exports both    | Code und Ergebnis exportieren        |
| :exports none    | weder Code noch Ergebnis exportieren |
| :eval never      | Block nicht ausführen                |
| :dir PFAD        | Arbeitsverzeichnis setzen            |

* Exportoptionen

#+begin_example
#+options: toc:3 num:t author:t date:t title:t
#+end_example

| Option     | Bedeutung                                   |
|------------+---------------------------------------------|
| toc:nil    | kein Inhaltsverzeichnis                     |
| toc:2      | Inhaltsverzeichnis bis Ebene 2              |
| num:nil    | Überschriften nicht nummerieren             |
| num:t      | Überschriften nummerieren                   |
| author:nil | Autor nicht exportieren                     |
| date:nil   | Datum nicht exportieren                     |
| title:nil  | Titel nicht exportieren                     |
| ^:nil      | Hoch- und Tiefstellung deaktivieren         |
| ^:{}       | Hoch- und Tiefstellung nur mit Klammern     |
| \n:t      | Zeilenumbrüche stärker erhalten             |
