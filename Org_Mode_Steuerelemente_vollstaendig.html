1. Hinweise zur Datei

Diese Datei ist vollständig und selbstständig.

Sie enthält absichtlich:

  • keine internen Links auf möglicherweise fehlende Überschriften,
  • keinen Verweis auf fig:architektur,
  • keine Bilddatei, die lokal vorhanden sein müsste,
  • keine ausführbaren Beispielblöcke, die beim Export automatisch gestartet werden.

Damit sollte der HTML-Export ohne die zuvor aufgetretenen Fehler wegen nicht auflösbarer Links funktionieren.

57. Praktische Abschlussübung

Lege ~/org/projekte.org an und verwende darin:

  • mindestens drei Überschriftenebenen,
  • mindestens fünf TODO-Aufgaben,
  • eigene TODO-Zustände,
  • zwei Tags,
  • drei Properties,
  • ein SCHEDULED-Datum,
  • eine DEADLINE,
  • eine wiederkehrende Aufgabe,
  • eine Tabelle,
  • eine Tabellenformel,
  • einen gültigen Link,
  • ein Kontrollkästchen,
  • einen Shell-Codeblock,
  • einen Python-Codeblock,
  • einen Clock-Eintrag.
